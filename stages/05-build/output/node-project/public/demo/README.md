# Real demo photo inputs

These four JPEGs are resized, metadata-stripped derivatives of operator-provided photographs from the real Happy Box project. They are included as hackathon sample data with the operator's permission.

| File | Purpose |
|---|---|
| `happy-box-outdoor.jpg` | Real neighborhood box image used by the Happy Box card |
| `shelf-mixed-catalog.jpg` | Multi-book shelf input for GPT-5.6 extraction |
| `shelf-math-science.jpg` | Multi-book mathematics and science shelf input |
| `shelf-thinking.jpg` | Multi-book philosophy and thinking shelf input |

The images contain no retained EXIF or GPS metadata. The original photographs are not committed. The demo seed creates the real Happy Box only; books must be proposed from one of these images and explicitly confirmed by a human. Do not treat filenames, model output, or this README as canonical bibliographic metadata.
