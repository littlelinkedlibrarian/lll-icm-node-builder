# Builder profile

Status: CONFIGURED
Configured: 2026-07-18

## Ownership mode

Agent-led complete build with human review. Learner decisions remain authoritative at stage boundaries and after each vertical slice.

## Technology preferences

Choose per project. Prefer the smallest maintainable stack that proves the approved journey. Keep contracts technology-neutral, external services behind adapters, and local development reproducible. Avoid adding infrastructure without an observable user requirement.

## Default connection path

Ask every run. Independent, LLL-compatible, hybrid own-domain plus LLL, LLL-hosted, and advanced managed-mesh paths remain available.

## OpenAI policy

When AI is selected, use OpenAI models exclusively behind server-side application adapters. Require reviewed structured outputs, model provenance, manual fallback, and explicit vector lifecycle behavior.

## Priority order

Learning depth, maintainability, privacy, delivery speed, operating cost.

## Checkpoints

Pause at every stage approval, after every vertical slice, and before infrastructure or external-state changes. A current explicit user approval may satisfy a checkpoint when it names the same scope and decisions.

## Completion evidence

Clean setup, automated tests, observed user journey, contract validation, secret scan, backup and recovery instructions, OpenAI outage behavior, and model/vector provenance when applicable.

## Ownership and accounts

The learner or their organization owns code, deployment accounts, domain or delegated hostname, DNS, TLS, OpenAI usage, backups, exports, and stored data. Record every LLL-hosted exception. LLL Central credentials and operations remain owned by the Central operator.

## Durable project rules

Accessible UI, least-data collection, explicit consent, human-reviewed AI writes, secrets kept server-side, owner-selected licensing and branding, local operation without OpenAI or network adapters, and truthful compatibility claims.
